# Quick Notes

A simple note-taking app built with vanilla HTML, CSS, and JavaScript.

## Features

- Add, edit, and delete notes
- Notes are saved in localStorage, so they persist after a refresh

## Built With

- HTML
- CSS
- JavaScript (no frameworks)

## How to Run

1. Clone the repo
2. Open `index.html` in your browser
